# Control Console — Brief

Goal: provide a coherent local-only web management interface for a DevSpace
instance. The operator must quickly understand service and connection health,
copy the correct MCP endpoint, manage configuration, inspect project versions,
diagnose requests and perform explicit recovery without encountering duplicate
or contradictory controls.

Audience: the technical owner operating DevSpace on Linux or Windows, including
remote use through an SSH port forward. The interface must work on desktop and
mobile, in Chinese and English, with light and dark themes.
