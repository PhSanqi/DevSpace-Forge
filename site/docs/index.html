安装与使用

DevSpace-Forge 提供 Windows x64 与 Linux x64 的完整离线发行包。下载、解压并配置允许访问的本地目录，再把 MCP 入口连接到你的 AI 客户端。

开始前

建议先准备一个专门的项目目录，只把需要 AI 开发的仓库加入 Allowed Roots。管理 Console 只在本机使用；远程连接只需要公开 MCP 地址。

下载与校验

打开最新 Release，选择对应平台的安装包及同名 .sha256.txt 校验文件。两端均包含 Node.js、Runtime 和 cloudflared。

前往 GitHub Releases ↗

Windows x64

解压 win-x64.zip，运行 Setup.exe。选择 Allowed Roots、服务端口以及可选的 Cloudflare Remote Tunnel 信息。已有安装可通过较新 Setup 进入更新流程，重要状态会保留。

Linux x64

解压 linux-x64.tar.gz，在目录内运行安装脚本。安装器打印本地 Origin、MCP 地址与首次授权信息；具体 systemd 服务名取决于普通安装还是命名实例。

./setup-linux.sh

连接 MCP

在 Cloudflare 创建 remotely-managed Tunnel，将公开主机名指向安装器显示的本地 Origin；在支持 MCP 的客户端中使用完整 HTTPS MCP 地址。第一次连接需完成 Owner 授权。

https://workspace.example.com/mcp

上面的 example.com 只是格式示例，请替换成你自己的域名。普通单实例安装不需要额外部署 Worker。

安全说明

只授权必要目录。Owner password、Tunnel token、API key、环境变量和私人项目路径都属于敏感信息，不要提交到 Git、Issue 或公开截图。更新 Runtime 前先检查是否有活动任务。
