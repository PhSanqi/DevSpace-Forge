01 / THE DIFFERENCE

把讨论和开发，留在同一条思路上。

你已经在 Chat 里讲清了需求，就不必再把它复制到另一套工具里重新解释。

01 / STAY IN FLOW

少切换一次，思路不断档。

讨论方案、查看代码、执行命令、检查结果，都从正在进行的对话发起。减少在 Chat、IDE 和终端间反复转述需求的时间。

讨论→执行→验证→继续
⌁

02 / CONTEXT THAT CONNECTS

让对话和项目证据接得上。

当前对话中的目标与反馈，结合按需读取的真实项目文件、Git 状态和任务日志，减少重复上传文件和重讲背景。上下文仍受客户端限制，并非无限记忆。

CHAT CONTEXT + LIVE PROJECT EVIDENCE
⌘

03 / ANOTHER USAGE PATH

把 Chat 的那一桶额度，也变成开发能力。

当前 OpenAI 规则下，Chat 与 Work / Codex 使用不同的额度池。当 Chat 客户端可以调用 MCP 时，规划、排查和本地开发可以直接在 Chat 中完成，不必把所有任务都挤到 agentic allowance。具体上限随套餐和产品规则变化，DevSpace 不提供或绕过额度。

CHAT ALLOWANCE + WORK / CODEX ALLOWANCE

额度说明：截至 2026-09，OpenAI 官方文档明确 Chat 的限制与 Work / Codex allowance 分开；具体可用量以你的套餐与 Usage 页面为准。OpenAI usage docs ↗
